# Подземелье призывателей (Summoners Dungeon)

Карточный рогалик: путешествие героя по подземелью + бои «карточные батлеры»
на арене 5×5. Движок — [zero_engine](https://github.com/elcarer/zero_engine)
(ECS, PixiJS 8), подключён «как есть» в `build/scripts/engine`.

Карты четырёх типов: **существа** (маршируют к базе врага), **заклинания**
(одноразовые эффекты), **строения** (ауры/бонусы соседям), **ловушки**
(скрытые триггеры «?»). Зона призыва расширяется по мере продвижения
(frontline, как в Stormbound). Референсы механик: Stormbound, Mighty Party.
Первая стихия «Сила» (красные): восемнадцать карт гоблинов — от быстрого
(рывок после призыва) до шамана, разыгрывающего Гоблина из колоды (существо
или приманку-ловушку), вождя со скидкой на гоблинов, ловчей приманки,
лучника с выстрелом после перемещения, бомблинга (достаёт ловушку из колоды
в руку), ассасина-добивания (1 жизнь после его удара — смерть) и грибницы,
каждый ход дающей энергию за свою жизнь; базовая колода 12 карт, сбор до 60.
Экономика боя: неизрасходованная
энергия + шкала конца хода «+карты ↔ +энергия» с ползунком (3 сферы на
первом ходу, +1 за каждый следующий; применяется автоматически по кнопке
«Конец»). Лимит руки — 7 карт, но проверяется только в конце хода: лишнее
сбрасываешь по своему выбору. Звук и музыка: свои треки для меню,
подземелья и боя + sfx на события боя (build/sound).

## Запуск

```bash
cd build
python dev_server.py 8147
# открыть http://127.0.0.1:8147/index.html
```

## Управление

- **WASD / стрелки** — движение героя по подземелью; **клик по полу** —
  герой сам идёт туда (поиск пути), клавиши перехватывают управление
- Клик по карте → клик по подсвеченной клетке — призыв / постройка
- Заклинание с прицелом: клик по карте → клик по врагу или его базе
- **Конец хода** — кнопка справа; **Esc** — снять выбор карты
- Редактор колоды и настройки — из главного меню (в колоде не более 3
  одинаковых карт)

## Структура

- `build/` — билд: движок + `scripts/game/` (loc, meta, dataCards, uiKit,
  dungeon, arena, deckScene, rewardScene, settingsScene, main) + арт
  (`images/ui`, `images/scenes` — арены, `images/sprites` — листы существ,
  `sound` — музыка и sfx, `font/Kereru.otf`)
- `for_work/` — рабочие материалы (арт-исходники, тесты) — в git не входят
- `PLAN.md` — план разработки и правила боя
- `HANDOFF.md` — сводка для продолжения работы (устройство, ловушки, журнал)

Статус: этап 0 + механические волны 2–3 + UX-волна + стихия «Сила» +
звук + поправки в1l–в1q готовы (смоук 280/280): весь интерфейс рассчитан
в базовом разрешении 1920×1080 (кнопки — натуральные 274×77, карты руки —
230×338), в коллекции редактора — только карты, что есть у игрока,
наведение на существо/строение в бою показывает его карту, из боя можно
просмотреть остаток колоды и сброс, клики по клеткам не блокируются
жетонами существ, ИИ противника тратит накопленную энергию и при её
избытке добирает карты (не копит десятки), drag&drop-призыв (переключается
в настройках), кнопки настроек/колоды в
подземелье и бою, меню «Продолжить/Новая игра» с сохранением забега
(этаж, герой, подземелье — переживают перезапуск; поражение снимает сейв),
лица карт — готовые картинки из images/cards (в руке — 2/3 размера, не
закрывают поле; в редакторе колоды обе панели — карточками-картинками),
механики «Скорость 1»/кровожадность/военный лагерь/«Гоблинская мина»
(ловушка на выбранной клетке: 3 урона врагу на ней + 1 соседям), карты
7–12: «Шаман гоблинов» (бесплатно призывает гоблина из колоды), «Вождь
гоблинов» (гоблины на 1 энергию дешевле), «Огненный дротик» (2 урона
существу или строению), «Землетрясение» (5 урона базе врага),
«Жертвоприношение» (убивает своё существо, 3 урона соседям), «Гоблинская
приманка» (враг, шагающий с соседней клетки, сходит на приманку и получает
1 урона) и карты 13–18: «Гоблинский лучник» (после перемещения — выстрел 1
впереди по вертикали или по базе), «Бомблинг» (ловушка из колоды — в руку),
«Гоблин-асассин» (добивает существо, оставшееся с 1 жизнью), «Паучий
наездник» (5/5), «Колдовское варево» (1 урон + 1 за каждое разыгранное
ранее), «Грибница» (постройка: каждый ход −1 жизнь, +1 энергия), карты
19–24: «Алтарь огня» (постройка: урон от ваших заклинаний и ловушек +1),
«Гоблинская засада» (враг на клетке ловушки — гоблины 2/2 на соседних
клетках), «Стена костров» (ряд клетки горит 3 ваших хода: 2 урона всем
в ряду в конце хода), «Огненное дыхание» (зачарованное существо при уроне
тянет заклинание из колоды в руку), «Поиск рун» (взять заклинание из
верхних 6 карт колоды), «Огнешар» (вся оставшаяся энергия — в урон),
в бою видна колода врага с рубашкой гоблинов и её просмотр, враги
подземелья — по архетипам на каждый этаж (банда гоблинов, мародёры,
засада, поджигатели, свита вождя, вождь-босс): колоды растут с глубиной —
больше карт, всё больше редких и эпических; ИИ врага добивает раненых,
ставит строения в тыл, а приманки — под бок юзам, разыгранная врагом
карта показывается слева не меньше секунды (игрок видит, что происходит),
стартовая колода — по 2 копии: Быстрый/Толстый/Боевой гоблин,
Кровожадность, Огненный дротик, Гоблинская приманка, энергия +
шкала «карты↔энергия» с растущим числом сфер (ползунок
— клик и drag по треку), лимит руки 7 с выборочным сбросом в конце хода,
«Конец хода» также по Пробелу, скорость анимаций боя — ползунок в
настройках (по умолчанию в 1,5 раза медленнее), наведение на врага в
подземелье — подсказка с именем и составом его колоды, лимит колоды —
не более 3 одинаковых карт, клик-перемещение по подземелью
с поиском пути, клики по полю боя без «мёртвых» полос у границ клеток,
в редакторе колоды наведение увеличивает карту до полного размера, а
стихии фильтруются рядом из 6 лого справа,
музыка сцен и sfx-события (каналы звука/музыки), единый курсор-картинка
images/ui/cur.png, миграция старых сейвов.
Подробности — в PLAN.md и HANDOFF.md.
