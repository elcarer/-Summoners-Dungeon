# Подземелье призывателей (Summoners Dungeon)

Карточный рогалик: путешествие героя по подземелью + бои «карточные батлеры»
на арене 5×5. Движок — [zero_engine](https://github.com/elcarer/zero_engine)
(ECS, PixiJS 8), подключён «как есть» в `build/scripts/engine`.

Карты четырёх типов: **существа** (маршируют к базе врага), **заклинания**
(одноразовые эффекты), **строения** (ауры/бонусы соседям), **ловушки**
(скрытые триггеры «?»). Зона призыва расширяется по мере продвижения
(frontline, как в Stormbound). Референсы механик: Stormbound, Mighty Party.
Первая стихия «Сила» (красные): шесть карт гоблинов — от быстрого (рывок
после призыва) до ловчей япы на перемещение; базовая колода 12 карт, сбор
до 60. Экономика боя: неизрасходованная энергия + 3 энергосферы на ход
(карта или +1 энергия — потратив все, завершаешь ход). Лимит руки — 7
карт, но проверяется только в конце хода: лишнее сбрасываешь по своему
выбору. Звук и музыка: свои треки для меню, подземелья и боя + sfx на
события боя (build/sound).

## Запуск

```bash
cd build
python dev_server.py 8147
# открыть http://127.0.0.1:8147/index.html
```

## Управление

- **WASD / стрелки** — движение героя по подземелью
- Клик по карте → клик по подсвеченной клетке — призыв / постройка
- Заклинание с прицелом: клик по карте → клик по врагу или его базе
- **Конец хода** — кнопка справа; **Esc** — снять выбор карты
- Редактор колоды и настройки — из главного меню

## Структура

- `build/` — билд: движок + `scripts/game/` (loc, meta, dataCards, uiKit,
  dungeon, arena, deckScene, rewardScene, settingsScene, main) + арт
  (`images/ui`, `images/scenes` — арены, `images/sprites` — листы существ,
  `sound` — музыка и sfx, `font/Kereru.otf`)
- `for_work/` — рабочие материалы (арт-исходники, тесты) — в git не входят
- `PLAN.md` — план разработки и правила боя
- `HANDOFF.md` — сводка для продолжения работы (устройство, ловушки, журнал)

лица карт — готовые картинки из images/cards (в руке — в оригинальном
