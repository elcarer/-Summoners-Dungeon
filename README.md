# Подземелье призывателей (Summoners Dungeon)

Карточный рогалик: путешествие героя по подземелью + бои «карточные батлеры»
на арене 5×5. Движок — [zero_engine](https://github.com/elcarer/zero_engine)
(ECS, PixiJS 8), подключён «как есть» в `build/scripts/engine`.

## Запуск

```bash
cd build
python dev_server.py 8147
# открыть http://127.0.0.1:8147/index.html
```

## Управление

- **WASD / стрелки** — движение героя по подземелью
- Клик по карте → клик по клетке — призыв существа (ряды у своей базы)
- **Конец хода** — кнопка справа; существа сами маршируют к базе врага
- **Esc** — снять выбор карты

## Структура

- `build/` — рабочий билд игры (движок + `scripts/game/`: данные, подземелье, арена, бут)
- `for_work/` — рабочие материалы (арт-исходники, тесты) — в git не входят
- `PLAN.md` — план разработки и правила арены v0

Референсы механик: Stormbound, Mighty Party. Статус: этап 0 (каркас),
все механики — стартовые заглушки, детали — в PLAN.md.
