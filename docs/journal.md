анимации и делает прочие ненужные для чистой логики вещи. Напиши новый
симулятор лиги, учтя все наши наработки и информацию, который будет работать
исключительно с данными и логикой, без ненужных нагрузок. Так мы сможем
запускать параллельно больше симуляций и они будут проходить быстрее.»

**for_work/sim_fast.mjs** — та же боевая логика ПРОДАКШН-КОДОМ без браузера:
- скрипты игры грузятся в `vm`-песочницу Node в порядке index.html (данные,
  локи, меню/сцены UI, вся арена) — БЕЗ pixi/engine/main; вместо них «дыры»
  (Proxy-заглушка: любой вызов/свойство проглатываются; `destroyed:false` —
  узлы «живы», как в браузере; `then:undefined` — await не вешается; toJSON и
  пустой итератор для безопасности снапшотов; СВОЙСТВА хранятся на инстансе —
  `node.__handIdx` не перетекают между «спрайтами»);
- `G` не пересобирается руками — литерал `const G = {…}` ВЫРЕЗАЕТСЯ из
  main.js целиком (resetRun/persistMeta/loseCard — продакшн-код, без дрейфа);
  шимы только metaState/settings (перезапишутся resetRun до каждого боя);
- планировщик на виртуальных часах (after(s,cb)/update(ms), созревшие —
  по времени назначения) + «насос кадров»: пока жив промис полухода, тикаем
  scheduler.update(100мс) + scene.update({deltaMS:100}) — анимации
  дорабатывают, логика идёт тем же путём, что в браузере;
- `__SIM`-драйвер — дословный перенос pageSimCode из sim_league.mjs (зеркало
  рассадки swap, копия enemyTurn, патчи animK=50/enemyPlayDelay/multi*-ноу-опы,
  обёртки счётчиков, W124 heroAbil/pass) + защита: enemyTurn/playerTurnStart
  вне драйвера блокируются с логом (поимка бага input-дыры, см. грабли);
- boot-прогрев: первый вход в меню отыгрывается ДО боёв (интро не мешает);
- leaguePlan/сиды/perHero/heroHp — дословно: планы боёв и записи СОВМЕСТИМЫ
  с sim_league (league_report/league_ai_report/compare едят как есть;
  из записей убраны только snaps — отчёты их не читают, файлы лиг вдвое
  меньше).
- **Скорость: 92мс/бой в среднем (замер 100 боёв), 0 ошибок — против 5–15с/бой
  у браузерного. Воркеров — сколько угодно, без портов/хрома/серверов.**
  Лаунчер **for_work/league_fast.sh** (копия надзора sim_league.sh: слоты,
  перезапуски, парты .league_part_N → штатный мёрж league_report).
