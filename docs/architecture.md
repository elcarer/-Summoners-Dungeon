## Листы существ (стандарт боя)

`images/sprites/<имя>_256.png` — сетка кадров **256×256**: 4 ряда анимаций
`front / back / right / left` (сверху вниз) по 6 кадров + json-манифест
(size/columns/fps/animations — формат loadCharacter движка, нейминг как у
knight_64: `walk_front` и т.д.). Загрузка: в main.js — `heroSheets`
(strength→goblin, growth→elf, wisdom→sorca; герой карты выбирается по
стихии забега `G.elem` в enter() сцен dungeon/world:
`ctx.heroSheet = ctx.heroSheets[G.elem] || strength`) и
`creatureSheets` → `ctx.creatureSheets` — реестр листов ПОЛЯ БОЯ:
goblin/elf/wisdom (по стихиям), wolf, bear (×1.1), ent (×1.3), plant
(×0.8), элементали water_el/air_el/spirit. Новые листы добавлять
записью в `creatureSheets` (main.js); карта указывает лист полем
`def.sheet`, у записи может быть `scale` — множитель к SPRITE_SCALE.

Отрисовка (arenaBoard.js `makeUnitNode`): `PIXI.AnimatedSprite(…, false)` —
autoUpdate=false, кадры тикает update() сцены (`body.update(ticker)` —
ТИКЕРОМ, не числом). Взгляд: игроку — `walk_back` (затылок, идёт вверх),
врагу — `walk_front` (анфас, идёт вниз); якорь (0.5, 0.85), масштаб 0.35
(фигура ~68px в клетке ~82×80, голова чуть выше клетки — так задумано).
Стоит — стоп-кадр 0; в движении — `setWalk(u, true)` + `glide()` (плавный
переезд 0.5с/animK = полный цикл походки; animationSpeed переписывается
каждый кадр — ползунок «Анимации» действует на живые юниты). Под ногами командное кольцо-эллипс
(синее/красное), атаки/жизни — бейджи в нижних углах, пипсы скорости у ног.
Спрайт `eventMode="none"` — клики уходят в клетки поля под существом.
Строения — по-прежнему домик-графика (это не существа; лагерь помечен
`+1⚔`). В `state()` у юнитов поле `spr` (есть ли спрайт-боди). Выбор листа —
`sheetOf` (arenaCore.js): СПЕРВА `def.sheet` карты (элементали Мудрости,
волк/медведь/древоброд/росянка), затем стихия (`growth` → `elf`,
`wisdom` → `sorca`, остальное → `goblin`). `def.creature` в выборе листа
НЕ участвует (на картах Роста это плейсхолдеры «goblin» — поле дискаунта
Вождя).

Тест-хендлы: `window.__GAME` — `stats()` (сцена/колода/бой/ошибка),
`menu` (buttons — подписи/масштаб/кегль, continueEnabled, press("continue"|

## Карты стихий (пайплайн)

Игра переводится на «настоящие» карты по стихиям. Тестовые карты (spear/merc/
wolf/fireball/banner/mine и пр.) УДАЛЕНЫ. Стихия «Сила» (красные, `strength`)
— первая: `str1..str6`, где цифра = файл лица карты
`build/images/cards/strength/<№>.png`. Лицо — ГОТОВОЕ изображение карты
(230×338, рамка/имя/статы нарисованы; тексты в картинке пока RU-тестовые):
- `uiKit.cardFace`: если у карты есть `img` — спрайт картинки, масштаб к
  высоте эталонной рубашки (330), поверх только точка редкости. Процедурная
  сборка (рубашка+подписи) осталась фолбэком для карт без `img`.
- Рука боя (`arenaHand.makeCardNode`): картинка в **2/3 размера** (~153×225),
  без технических подписей/плашек (вся информация нарисована на карте);
  нижний край уходит за экран (HAND_Y 754), верх карты ниже поля (поле
  кончается на y=517) — **клетки боя не закрываются**. Выбор/наведение —
  увеличение ×1.12 и золотая рамка `selframe`, БЕЗ подъёма карты.
  Недоступная (дорогая) карта — затемнена тинтом 0x9f9f9f (НЕ прозрачность).
  Веер: spread = min(150, 1050/n). Пока выбрана карта — ВСЯ рука
  неинтерактивна (клики уходят в поле): снять выбор — Esc, клик по фону или
  клик мимо валидных клеток (onCellTap → deselect()). Перетаскиваемая в
  drag-режиме карта — полноразмерная (читаемость при прицеливании).
- Предзагрузка: main.js грузит `images/cards/<def.img>.png` для всех карт с
  `img` в uiTextures (uiTex бросает исключение, если не загрузить — бут умрёт).
- **Подтипы (subtype) и типы эффекта (kind) — спека юзера** (СТАТИЧЕСКОЕ
  ПРАВИЛО): юзер ведёт их сам в for_work/cards.txt (ID:N) и сообщениями;
  брать ТОЛЬКО оттуда, не выводить по названиям карт. Подтип — только
  явное поле subtype; `creature` в данных — плейсхолдер листа поля боя
  (не тип существа).
- Базовая колода игрока: 12 карт = по 2 копии str1/str2/str3/str4/str9/str12
  (в1q, просил юзер); DECK_MIN 12,
  DECK_MAX 60, **DECK_COPIES 3** — не более 3 одинаковых карт в колоде
  (deckScene api.add + затемнение «добитой» карты в коллекции). Пул наград —
  вес повторами (обычные ×3, редкая ×2, эпик ×1).
- **Гейты подземелий (w12, просил юзер)**: открытый мир живёт по минимуму
  12 (стартовые колоды — бои с отрядами `deckMinFor(1)`); ПОДЗЕМЕЛЬЯ
  требуют свои 16+: вход на 1-й этаж и все бои этажа —
  `caveDeckFor(floor) = 15+floor` (вход 16, этаж 2 — 17), спуск с этажа N
