## Запуск и тесты

```bash
cd build && python dev_server.py 8147     # http://127.0.0.1:8147/index.html
bash for_work/smoke.sh                    # полный смоук: 45 проверок (сейчас 45/45)
```

`smoke.sh` поднимает сервер 8147 + headless Chrome (порт 9333, --mute-audio,
свой профиль `for_work/.chrome_profile`) и гонит `for_work/smoke_test.mjs`
под watchdog-ом `for_work/runtest.sh`. Отдельные пробы: `probe_visual.mjs`
(подсветка арены), `probe_deck.mjs` (редактор колоды). CDP-драйвер —
`cdp.mjs` в корне (connect/evalJs/shot/mouse).

**dev_server.py — только ThreadingHTTPServer.** Оригинальный
`nocache-server.py` движка однопоточный: Chrome грузит десятки `<script>`
параллельными соединениями, часть теряется → случайные
«createAssets/GAME_DATA is not defined». Удалён из build.

## Устройство (build/scripts/game/)

| файл | роль |
|---|---|
| `loc.js` | локализация RU/EN: `GAME_LOC.t(key, vars)`, `setLang`. Все тексты игры |
| `meta.js` | localStorage: настройки (`sd_settings`: sound/music 0..10, lang), коллекция+колода (`sd_meta`) |
| `dataCards.js` | карты (тип/цена/редкость/стихия/статы/эффекты), колоды энкаунтеров, пул наград, лимиты (DECK 8..15, TRAP_SLOTS 2) |
| `uiKit.js` | T (текст), **fit()** (вписать текст), button/chip, cardFace, dimBg, **scrollPane** (колесо/ползунок/трек) |
| `dungeon.js` | сцена подземелья: ASCII-карта 30×17 (TS 40), WASD (движок character+camera), жетоны врагов, выход за главарём |
| `arena.js` | сцена боя 5×5: все механики (см. «Правила боя»), SCENE_GRID — границы клеток поверх арта |
| `deckScene.js` | редактор колоды: фильтры-чипы (тип/цена/редкость/стихия), два scrollPane |
| `rewardScene.js` | трофей после победы: 1 из 3 карт в коллекцию |
| `settingsScene.js` | настройки: звук (мастер аудио движка), музыка (хранится), язык |
| `main.js` | бут: init движка → шрифт Kereru (FontFace) → ассеты → мета/настройки → сцены → меню |

Сцены через `createScenes` (add/go/is, хуки enter/exit/update). UI всех сцен
кроме подземелья — в корне `ui` 1280×720, вписывается в окно letterbox;
`__GAME.toScreen(x,y)` переводит дизайн-координаты в экранные (для кликов).
Ассеты: `images/ui/` (кит из for_work/finish), `images/scenes/{1,2}.png`
(фоны арен с нарисованной сеткой), `images/sprites/knight_64` (заглушка
героя), `font/Kereru.otf`.

Тест-хендлы: `window.__GAME` — `stats()` (сцена/колода/бой/ошибка),
`arenaApi` (endTurn, playCardAt, castSpell, playTrap, select, deployRows,
state, _kill, _spawn), `deckApi` (add/remove/setFilter/visibleIds/scroll/
paneState), `rewardApi`, `settingsApi`, `test.setHeroPos`, `loc`.

## Правила боя (актуальные)

- Поле 5×5; ряд 0 — база врага, ряд 4 — база игрока. Базы 15 (игрок) /
  baseHp энкаунтера. Мана: +1/ход, кап 10 (враг 8). Рука: старт 4, +2/ход,
  лимит 6; колода циклится (сброс↔колода). Конец хода — кнопка справа.
- **Зона призыва**: по умолчанию ОДИН ряд перед базой ([3] у игрока, [1] у
  врага). Расширяется только вперёд — до ряда перед самым выдвинутым своим
  существом/строением: существо на ряду 3 → [2,3]; на ряду 2 → [1,2,3].
- **Типы карт**: unit (cost/atk/hp/speed, марширует); spell (fireball — 2
  урона в существо/базу по прицелу; insight — взять 3 карты, без цели);
  building (banner 0/3, аура +1/+1 всем своим юнитам, стоит, блокирует
  клетку, гибнет от урона); trap (mine — «?» у поля, при гибели своего
  существа от вражеского юнита: 1 урон всем врагам в ряду убийцы, затем
  сбрасывается; слотов 2 на сторону).
- Марш в начало хода владельца: свободно — шаг; впереди враг — удар
  (урон = curAtk с аурами); край — удар по базе и гибель; своим не пройти.
- Ауры пересчитываются при каждом addUnit/гибели строения (юнит,
  размещённый ПОСЛЕ строения, тоже получает ауру).
- ИИ играет всеми типами: юниты/строения в свою зону (передний ряд
  приоритетно), fireball — в сильнейшего юнита игрока или базу, ловушки при
  свободных слотах.
- Победа → экран «ПОБЕДА!» → авто через 1.4с в трофей (1 из 3 в коллекцию)
  → подземелье. Поражение → кнопка «В меню».
- Коллекция/колода/настройки переживают забеги (localStorage), resetRun их
  не трогает. Награда сохраняется сразу.

## Геометрия арены поверх арта

`images/scenes/N.png` (1920×1080 → дизайн ×2/3). Сетка на арте слегка
неравномерная → границы клеток заданы массивами per-scene (`SCENE_GRID` в
arena.js): cols [427, 509, 594, 679, 765, 850], rows сцена1
[112, 198, 276, 353, 433, 517], сцена2 [119, …]. Подсветка —
полупрозрачные прямоугольники (зелёные — зона призыва, красные — прицел
спелла) с отступом 2px внутрь. Измерено градиентами краёв клеток (скрипт в
истории сессии), выравнивание проверено масочным замером скрина (±3px).
Новые арены: прогнать детект линий и дописать SCENE_GRID.

## СВОД ЛОВУШЕК

**Pixi v8 (dll/pixi.min.js 8.19):**
- Text/Graphics/Sprite по умолчанию eventMode **'auto' = перехватывают
  клики** (Container — 'passive'). Надпись поверх кнопки съедает pointertap:
  на всех текстах-оверлеях `eventMode="none"`, обработчики — на контейнере
  (всплытие ловит детей) или на спрайте под текстом.
- `Container` НЕ имеет свойства `userData` — создаётся присваиванием
  `c.userData = {...}` (обращение `c.userData.x = …` падает).
- `getLocalBounds()` на свежесозданных Text/Graphics врёт (до рендера) —
  высоту скролл-контента задавать ЯВНО из построителя.
- `AnimatedSprite(anims.wait, false)` — автовоспроизведение остаётся
  системе персонажей (true = двойной прогон).
- Спрайт Text масштабируется scale.x — для вписывания сначала кегль, потом
  сжатие (см. `GAME_UI.fit`).

**Движок zero_engine:**
- `scripts/data/units.js` обязателен в index.html ПЕРЕД engine.js — ядро
  читает глобаль UNIT_CONFIGS в init() (это не только демо-данные).
- Аудио: мастер `audio.setVolume(0..1)`; шаги настроек 0..10 → /10.
- Игровые скрипты — в конце `<body>` (main.js ищет #boot).

**Харнесс / среда:**
- Headless Chrome `--window-size 1300,760` даёт canvas ~1284×660 — клики
  только через `__GAME.toScreen`, не в лоб.
- `cmd1 && long & sleep; node …` — `&` отрывает ВЕСЬ `cd && cmd`, node
  стартует в старом cwd; инлайн `node -e` с кавычками молча ломается —
  пробы писать файлами в for_work/.
- Скриншоты для анализа: Read уводит в CDN; VLM-пробой по CDN-ссылке с
  обратными слэшами пути иногда падает — надёжнее численный замер масок
  (numpy по цветовым полосам).
- CDP: evaluate >30с убивается; wmic сломан (PowerShell EncodedCommand);
  убивать только свои PID (netstat по порту).
