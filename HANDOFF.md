## Запуск и тесты

```bash
cd build && python dev_server.py 8147     # http://127.0.0.1:8147/index.html
bash for_work/smoke.sh                    # полный смоук (последний полный — 748/748, 2026-10-31; счётчик растёт с волнами)
bash for_work/mini.sh for_work/quest_test.mjs   # мини-пробы волн: свой сервер 8174 + chrome 9344

```

`smoke.sh` поднимает сервер 8147 + headless Chrome (порт 9333, --mute-audio,
свой профиль `for_work/.chrome_profile`) и гонит `for_work/smoke_test.mjs`
под watchdog-ом `for_work/runtest.sh` (полный лог — /tmp/test_out.log,
stdout обёртки — только tail; rc ненадёжен — сверять итоговую строку).
Живой регресс — `for_work/regress_v5.sh` (последовательно, мини-порты):
probe_fix3 (эталон эпохи мира), probe_world, probe_tiles, probe_v7shots,
mini_test, mini_fix_test, quest_test, probe_decay2, probe_honor2..honor7,
probe_wander, probe_time, probe_bridge, probe_tim2, probe_tim3, probe_w18,
probe_w19, probe_w20, probe_w21, probe_w22, probe_fix1, probe_fix2, probe_ai_smart (свой раннер, 8164/9347) + оффлайн
tiles_offline /
forest_offline; генератор отдельно — `check_worldgen.mjs` (2000 сидов).
Прочие пробы — история волн, не перепрогонять. Паттерн
пробы: свой порт 8174+ и одноразовый Chrome-профиль.
CDP-драйвер — `cdp.mjs` в корне (connect/evalJs/shot/mouse).

**Картотека карт** (w24, просил юзер) — отдельная от игры программка
`build/tools/cards.html`: открывается двойным кликом (file://, без fetch —
только `<script>`/img) или по `tools/cards.html` на дев-сервере. Просмотр
всех карт каталога (растёт с волнами; сейчас 235 + карты персонажей) по
фильтрам (стихия/тип/редкость/цена/
поиск/сортировка; кнопки-опции включаются/выключаются независимо — w29),
подробности карты (лицо + описание из loc.js + сырые
параметры), конструктор колод (капы DECK_MAX/DECK_COPIES соблюдаются,
пресеты стартовых колод, кривая цены) с сохранением в файл (JSON
`{game, kind:"deck", version, name, cards:{id:count}}`) и в память
браузера (именованные слоты + автосохранение). Данные берёт из
`cardsData.js`, тексты — из `loc.js` (RU/EN переключается). Тестовый API —
`window.__CARDSDB` (probe_w24.mjs).

**dev_server.py — только ThreadingHTTPServer.** Оригинальный
`nocache-server.py` движка однопоточный: Chrome грузит десятки `<script>`
параллельными соединениями, часть теряется → случайные
«createAssets/GAME_DATA is not defined». Удалён из build.
